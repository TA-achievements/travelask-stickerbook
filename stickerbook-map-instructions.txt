СТИКЕРБУК · КАК ДОБАВИТЬ МОДЕРАТОРА НА КАРТУ

1. Открой файл на GitHub

Перейди в репозиторий Стикербука:
https://github.com/TA-achievements/travelask-stickerbook

Открой geography-data.js и нажми значок карандаша «Edit this file».
Имя модератора копируй из профиля Стикербука, сохраняя порядок имени и
фамилии. По этому имени карта подтягивает аватарку и ссылку на профиль.

2. Если город уже есть на карте

Найди блок с нужным городом и добавь имя в строку members.
Каждое имя должно быть в двойных кавычках. Между именами — запятая.

Было:
    members: ["Терентьева Анастасия"],

Стало:
    members: ["Терентьева Анастасия", "Фамилия Имя"],

Вместо «Фамилия Имя» вставь имя нового модератора из Стикербука.
Оба участника будут доступны по одной отметке города.

3. Если города ещё нет на карте

Возьми координаты центра города из онлайн-карты. Первое число — широта
(lat), второе — долгота (lon). Дробные числа пиши через точку и без
кавычек. Если у координаты есть знак минус, сохрани его.

Скопируй блок ниже и вставь его перед последней строкой ]; в файле.
Подставь свой город, страну, координаты и имя из профиля.

  {
    city: "Варшава",
    country: "Польша",
    lat: 52.23,
    lon: 21.01,
    members: ["Фамилия Имя"],
  },

Сохрани запятую после закрывающей фигурной скобки }, и последнюю
строку ];. В пастельном атласе страна с первой отметкой автоматически
получит более насыщенный оттенок.

4. Сохрани и проверь

Нажми Commit changes, затем подтверди сохранение во всплывающем окне.
Когда GitHub опубликует изменения, обнови вкладку «География команды».
Нажми на город в списке и проверь отметку, имя и ссылку на профиль.

Если имя есть в карточке города, а фото и ссылка на профиль не появились,
сверь написание имени в members с тем, как оно указано в Стикербуке.
