КАК ЗАПОЛНЯТЬ МИНИ-АНКЕТУ

В data.js у каждого участника теперь есть поля:

"birthday": null,
"zodiac": null,
"city": null,
"hobby": null,
"interview": null,
"fact": null

Заменяй null только у нужного человека, например:

"birthday": "10 июня",
"zodiac": "Близнецы",
"city": "Москва",
"hobby": "Танцы",
"interview": "https://t.me/имя_канала/123",
"fact": "Люблю путешествия и мощную музыку"

Можно заполнить только часть полей. Пустые/null строки на сайте не показываются.
Если заполнена только ссылка на интервью, появится только кнопка «Читать интервью».

Ссылка Telegram может вести прямо на конкретное сообщение.
Для закрытого канала сообщение откроется только у пользователей, у которых есть к нему доступ.
